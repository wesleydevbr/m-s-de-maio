# Maio Amarelo 2026 - Paz no Trânsito

Projeto simples de conscientização sobre segurança viária, desenvolvido com HTML.

---

## 📖 Sobre o projeto

Uma página informativa focada no movimento Maio Amarelo, incluindo:

- Explicação sobre a origem e o significado da cor amarela.
- Detalhes da campanha de 2026: "Paz no trânsito começa por você".
- Dicas práticas para um trânsito mais seguro.

O objetivo do projeto foi praticar estruturação de conteúdo semântico em HTML e formatação de textos.

---

## 🛠️ Tecnologias utilizadas

- HTML5

---

## 🎯 Objetivo

Este projeto foi desenvolvido como forma de estudo para praticar:

- Estruturação de tags HTML (`<p>`, `<ul>`, `<li>`).
- Inserção e acessibilidade de imagens (`<img>`).
- Estilização básica inline para destaque de mensagens de alerta.

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, aprendi:

- Como organizar informações hierarquicamente para facilitar a leitura.
- A importância de textos alternativos (`alt`) em imagens.
- Uso de tags de ênfase para mensagens de segurança.
